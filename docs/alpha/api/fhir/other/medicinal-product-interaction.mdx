# MedicinalProductInteraction

<span className="fhir-maturity" data-level="0">Draft</span>

## Top-level elements

| Element | Type(s) | Cardinality | Description |
| --- | --- | --- | --- |
| `subject` | `Reference` | `0..*` | The medication for which this is a described interaction |
| `description` | `string` | `0..1` | The interaction described |
| `interactant` | `BackboneElement` | `0..*` | The specific medication, food or laboratory test that interacts |
| `type` | `CodeableConcept` | `0..1` | The type of the interaction e.g. drug-drug interaction, drug-food interaction, drug-lab test interaction |
| `effect` | `CodeableConcept` | `0..1` | The effect of the interaction, for example "reduced gastric absorption of primary medication" |
| `incidence` | `CodeableConcept` | `0..1` | The incidence of the interaction, e.g. theoretical, observed |
| `management` | `CodeableConcept` | `0..1` | Actions for managing the interaction |
