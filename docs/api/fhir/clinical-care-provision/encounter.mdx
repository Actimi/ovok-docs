# Encounter

<span className="fhir-maturity" data-level="3">Trial Use 3</span>
<span className="fhir-category">Clinical — Care Provision</span>

An interaction during which services are provided.

The standard FHIR R5 interactions for `Encounter` are mounted under your
selected release tier:

| Vread      | `GET`    | `/Encounter/[id]/_history/[vid]` |
| Update     | `PUT`    | `/Encounter/[id]` |

(`Content-Type: application/fhir+json`) and accept the standard
`Accept: application/fhir+json` header.
