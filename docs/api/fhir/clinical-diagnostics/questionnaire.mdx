# Questionnaire

<span className="fhir-maturity" data-level="3">Trial Use 3</span>
<span className="fhir-category">Clinical — Diagnostics</span>

Structured set of questions.

## Endpoints

The standard FHIR R5 interactions for `Questionnaire` are mounted under your
selected release tier:

<ApiBase surface="fhir" path="/Questionnaire" inline={false} />

| Interaction | Method | Path |
| --- | --- | --- |
| Read       | `GET`    | `/Questionnaire/[id]` |
| Vread      | `GET`    | `/Questionnaire/[id]/_history/[vid]` |
| Update     | `PUT`    | `/Questionnaire/[id]` |
| Patch      | `PATCH`  | `/Questionnaire/[id]` |
| Delete     | `DELETE` | `/Questionnaire/[id]` |
| Create     | `POST`   | `/Questionnaire` |
| Search     | `GET`    | `/Questionnaire?...` |

All calls expect FHIR-flavoured JSON
(`Content-Type: application/fhir+json`) and accept the standard
`Accept: application/fhir+json` header.
