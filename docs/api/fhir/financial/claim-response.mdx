# ClaimResponse

<span className="fhir-maturity" data-level="2">Trial Use 2</span>
<span className="fhir-category">Financial</span>

Adjudication response to a Claim.

## Endpoints

The standard FHIR R5 interactions for `ClaimResponse` are mounted under your
selected release tier:

<ApiBase surface="fhir" path="/ClaimResponse" inline={false} />

| Interaction | Method | Path |
| --- | --- | --- |
| Read         | `GET`    | `/ClaimResponse/[id]` |
| Vread        | `GET`    | `/ClaimResponse/[id]/_history/[vid]` |
| Update       | `PUT`    | `/ClaimResponse/[id]` |
| Patch        | `PATCH`  | `/ClaimResponse/[id]` |
| Delete       | `DELETE` | `/ClaimResponse/[id]` |
| Create       | `POST`   | `/ClaimResponse` |
| Search       | `GET`    | `/ClaimResponse?...` |
| History      | `GET`    | `/ClaimResponse/[id]/_history` |
| Type-history | `GET`    | `/ClaimResponse/_history` |

All calls expect FHIR-flavoured JSON
(`Content-Type: application/fhir+json`) and accept the standard
`Accept: application/fhir+json` header.
