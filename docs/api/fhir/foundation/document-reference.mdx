# DocumentReference

<span className="fhir-maturity" data-level="3">Trial Use 3</span>
<span className="fhir-category">Foundation</span>

Reference to a document made available for retrieval.

## Endpoints

The standard FHIR R5 interactions for `DocumentReference` are mounted under your
selected release tier:

<ApiBase surface="fhir" path="/DocumentReference" inline={false} />

| Interaction | Method | Path |
| --- | --- | --- |
| Read         | `GET`    | `/DocumentReference/[id]` |
| Vread        | `GET`    | `/DocumentReference/[id]/_history/[vid]` |
| Update       | `PUT`    | `/DocumentReference/[id]` |
| Patch        | `PATCH`  | `/DocumentReference/[id]` |
| Delete       | `DELETE` | `/DocumentReference/[id]` |
| Create       | `POST`   | `/DocumentReference` |
| Search       | `GET`    | `/DocumentReference?...` |
| History      | `GET`    | `/DocumentReference/[id]/_history` |
| Type-history | `GET`    | `/DocumentReference/_history` |

All calls expect FHIR-flavoured JSON
(`Content-Type: application/fhir+json`) and accept the standard
`Accept: application/fhir+json` header.
