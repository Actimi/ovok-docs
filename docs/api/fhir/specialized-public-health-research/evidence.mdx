# Evidence

<span className="fhir-maturity" data-level="1">Trial Use 1</span>
<span className="fhir-category">Specialized — Public Health & Research</span>

Single piece of evidence — measurement, association, claim.

## Endpoints

The standard FHIR R5 interactions for `Evidence` are mounted under your
selected release tier:

<ApiBase surface="fhir" path="/Evidence" inline={false} />

| Interaction | Method | Path |
| --- | --- | --- |
| Read       | `GET`    | `/Evidence/[id]` |
| Vread      | `GET`    | `/Evidence/[id]/_history/[vid]` |
| Update     | `PUT`    | `/Evidence/[id]` |
| Patch      | `PATCH`  | `/Evidence/[id]` |
| Delete     | `DELETE` | `/Evidence/[id]` |
| Create     | `POST`   | `/Evidence` |
| Search     | `GET`    | `/Evidence?...` |
| History    | `GET`    | `/Evidence/[id]/_history` |
| Type-history | `GET`  | `/Evidence/_history` |

All calls expect FHIR-flavoured JSON
(`Content-Type: application/fhir+json`) and accept the standard
`Accept: application/fhir+json` header.
