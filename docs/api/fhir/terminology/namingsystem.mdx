# NamingSystem

<span className="fhir-maturity" data-level="3">Trial Use 3</span>
<span className="fhir-category">Terminology</span>

Definition of a system of identifiers.

## Endpoints

The standard FHIR R5 interactions for `NamingSystem` are mounted under your
selected release tier:

<ApiBase surface="fhir" path="/NamingSystem" inline={false} />

| Interaction | Method | Path |
| --- | --- | --- |
| Read       | `GET`    | `/NamingSystem/[id]` |
| Vread      | `GET`    | `/NamingSystem/[id]/_history/[vid]` |
| Update     | `PUT`    | `/NamingSystem/[id]` |
| Patch      | `PATCH`  | `/NamingSystem/[id]` |
| Delete     | `DELETE` | `/NamingSystem/[id]` |
| Create     | `POST`   | `/NamingSystem` |
| Search     | `GET`    | `/NamingSystem?...` |

All calls expect FHIR-flavoured JSON
(`Content-Type: application/fhir+json`) and accept the standard
`Accept: application/fhir+json` header.
