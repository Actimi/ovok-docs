# ValueSet

<span className="fhir-maturity" data-level="5">Normative</span>
<span className="fhir-category">Terminology</span>

Set of codes drawn from one or more code systems.

## Endpoints

The standard FHIR R5 interactions for `ValueSet` are mounted under your
selected release tier:

<ApiBase surface="fhir" path="/ValueSet" inline={false} />

| Interaction | Method | Path |
| --- | --- | --- |
| Read       | `GET`    | `/ValueSet/[id]` |
| Vread      | `GET`    | `/ValueSet/[id]/_history/[vid]` |
| Update     | `PUT`    | `/ValueSet/[id]` |
| Patch      | `PATCH`  | `/ValueSet/[id]` |
| Delete     | `DELETE` | `/ValueSet/[id]` |
| Create     | `POST`   | `/ValueSet` |
| Search     | `GET`    | `/ValueSet?...` |
| History    | `GET`    | `/ValueSet/[id]/_history` |
| Type-history | `GET`  | `/ValueSet/_history` |

All calls expect FHIR-flavoured JSON
(`Content-Type: application/fhir+json`) and accept the standard
`Accept: application/fhir+json` header.
